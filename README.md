# ShiftLab SOC

A browser-based SOC shift simulator for practicing Security Operations Center analyst skills — alert triage, log pivoting, threat hunting, phishing analysis, escalation, and shift handovers — across Security Onion and Splunk-style consoles.

It runs entirely in the browser. There's no server, no install, and no data leaves your machine. Open `index.html` locally, or visit the hosted page.

## Use it freely

Anyone is welcome to use, copy, modify, and share this code. No permission needed — have at it, whether you're a student, an instructor, or just brushing up.

## About

Built with [Claude](https://www.anthropic.com/claude) to develop real, hands-on SOC analyst skills and critical security thinking. Every scenario reshuffles its hosts, IPs, and noise on each run, so you investigate rather than memorize.

All organizations, people, domains, and IP addresses in the simulator are fictional.
